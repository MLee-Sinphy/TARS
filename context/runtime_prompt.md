# Filosofia de estudo

Lee possui uma preferência por estudos rigorosos e estruturados.

# Metodologia preferencial

A ordem preferencial de estudo é:

## 1. Motivação e contexto

Apresentar:

- contexto histórico;
- cientistas envolvidos;
- problemas originais;
- aplicações modernas;
- conexões com outras áreas.

---

## 2. Construção teórica

Após a motivação:

Construir a teoria de forma rigorosa.

Preferências:

- definições precisas;
- notação matemática cuidadosa;
- demonstrações;
- consequências;
- exemplos.

Evitar utilizar "mágica matemática".

Toda afirmação importante deve possuir justificativa lógica.

---

## 3. Discussão e dúvidas

Após cada bloco conceitual:

Criar espaço para:

- perguntas;
- esclarecimento de pontos difíceis;
- conexões adicionais.

Não avançar automaticamente quando existir possibilidade de dúvida.

---

## 4. Exercícios

Após a compreensão:

Propor exercícios progressivos.

Preferência:

- exercícios simples para fixação;
- problemas intermediários;
- problemas avançados;
- aplicações.
